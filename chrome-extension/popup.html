Sélectionnez une fiche. Le mot de passe reste masqué dans le panneau.

Seuls le nom de la fiche, l'identifiant, le mot de passe choisi et ce message seront partagés. Les autres données du coffre ne sont pas incluses.

Paramètres

Tant que ce panneau reste ouvert et déverrouillé, les identifiants correspondants sont remplis automatiquement sur les sites autorisés. Sa fermeture verrouille toujours le coffre. Vous pouvez également choisir un délai d’inactivité.

Verrouillage automatique actif.

Le panneau doit rester ouvert pour autoriser le remplissage automatique. Seules les interactions dans ce panneau comptent comme activité. « Jamais » désactive seulement l’inactivité : fermeture et verrouillage manuel restent actifs, et les requêtes au serveur expirent normalement. Aucun secret n’est enregistré.
